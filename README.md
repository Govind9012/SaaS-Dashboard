# SaaS Dashboard with RBAC & Mock Webhooks

This project contains a full-stack SaaS dashboard demo built with a React + Vite frontend and a FastAPI + PostgreSQL backend.

## Features

- JWT authentication with password hashing and role-based access control.
- Admin and Standard User roles with backend enforcement.
- Product catalog with search, filters, pagination, and detail views.
- Simulated checkout that stores orders and pending transactions.
- Mock webhook processing with HMAC validation, persisted duplicate-event protection, and idempotency.
- Admin analytics derived from PostgreSQL-backed data.
- Swagger/OpenAPI docs generated by FastAPI.

## Local setup

1. Copy `.env.example` to `.env` and set secrets as needed.
2. Start PostgreSQL:
   ```bash
   docker compose up -d db
   ```
3. Create and activate a Python virtual environment:
   ```bash
   cd backend
   python -m venv .venv
   . .venv/bin/activate
   pip install -r requirements.txt
   ```
4. Run database migrations:
   ```bash
   alembic upgrade head
   ```
5. Start the backend:
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
6. Start the frontend:
   ```bash
   cd frontend
   npm install
   npm run dev -- --host 0.0.0.0
   ```

## Environment variables

Create a `.env` file in the project root based on [.env.example](.env.example). The following variables are required for local development and a production-like setup:

```bash
DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/saasdb
JWT_SECRET_KEY=replace-with-a-long-random-secret
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=120
WEBHOOK_SECRET=replace-with-a-webhook-secret
ADMIN_EMAIL=admin@saas.local
ADMIN_PASSWORD=AdminPass123!
FRONTEND_URL=http://localhost:5173
VITE_API_URL=http://localhost:8000
```

> Note: The environment variables listed in this README are intentionally limited-use placeholders for demonstration and local testing. They are not production secrets and are documented here for convenience only. These demo values are expected to expire automatically after 3 days.

## Sample webhook request

```bash
curl -X POST http://localhost:8000/api/webhooks/mock \
  -H "Content-Type: application/json" \
  -H "X-Signature: $(python - <<'PY'
import hashlib, hmac, json
payload = {"event_id": "evt-demo-001", "event_type": "order.paid", "order_id": 1, "amount": 89.0, "currency": "USD"}
body = json.dumps(payload).encode()
print(hmac.new(b'replace-with-a-webhook-secret', body, hashlib.sha256).hexdigest())
PY
)" \
  -d '{"event_id": "evt-demo-001", "event_type": "order.paid", "order_id": 1, "amount": 89.0, "currency": "USD"}'
```

## Deployment

This project is structured for Render. Add the same environment variables to the Render service and point the frontend API URL to the deployed backend.

## Security notes

- Never commit `.env` or credentials.
- Backend authorization is enforced on every admin route.
- The frontend is never treated as the source of RBAC decisions.
- All price and total calculations happen on the backend.
